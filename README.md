# موقع «البيني» — الموقع التعريفي المبدئي

موقع عربي RTL لمشروع «البيني»: منصة عربية للدراسات البينية مدعومة بالذكاء الاصطناعي (قيد التطوير).

## ملاحظات مهمة

- الموقع **تعريفي فقط**: لا Backend، لا قاعدة بيانات، لا ذكاء اصطناعي فعلي، لا مفاتيح API.
- النموذج التفاعلي في قسم `Demo` يعمل ببيانات ثابتة من `content/demo.ts` مع تنبيه واضح أنه تصوري.
- جميع النصوص العربية مركزية في `content/site.ts` لتسهيل المراجعة والتعديل.
- Design Tokens (الألوان والخطوط) في `tailwind.config.ts`.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## البناء والنشر

```bash
npm run build
npm start
```

### النشر على Vercel

1. ارفع المجلد إلى مستودع GitHub.
2. استورد المستودع في Vercel — الإعدادات الافتراضية لـ Next.js تكفي.
3. لا توجد متغيرات بيئة مطلوبة.

## البنية

```
app/            الصفحات (الرئيسية، الخصوصية، الشروط، 404)
components/     مكونات قابلة لإعادة الاستخدام
content/        المحتوى العربي المركزي وبيانات الديمو
public/         الشعارات وfavicon وصورة Open Graph
```

## الخطوط

Alexandria للعناوين وIBM Plex Sans Arabic للنصوص، تُحمّل عبر `next/font/google` تلقائيًا.

## الوصول والأداء

- `lang="ar"` و`dir="rtl"` على مستوى الجذر.
- دعم `prefers-reduced-motion`.
- تنقل كامل بلوحة المفاتيح مع حالات تركيز ظاهرة.
- لا فيديو ثقيل ولا مكتبات حركة خارجية.
