# موقع «البيني» — الموقع التعريفي والعرض الحي

موقع عربي RTL لمشروع «البيني»: منصة بحث وتحليل بيني مدعومة بالذكاء الاصطناعي (قيد التطوير).
مبني وفق مرجع التسليم v2 (19 أغسطس 2026) وخريطة المعرفة المرجعية العربية v1.2.

## ملاحظات مهمة

- الموقع **تعريفي فقط**: لا Backend، لا قاعدة بيانات، لا ذكاء اصطناعي فعلي، لا مفاتيح API.
- النموذج التفاعلي في `components/Demo.tsx` يعمل ببيانات ثابتة من `content/demo.ts`، مع تنبيه صريح بأنه توضيحي ولا يعمل خلفه النظام الفعلي.
- جميع النصوص العربية مركزية في `content/site.ts` لتسهيل المراجعة والتعديل.
- Design Tokens (الألوان والخطوط) في `tailwind.config.ts` — لم تتغير عن الهوية المعتمدة.

## بنية الصفحة

الهيرو ← المشكلة ← لماذا يختلف ← المناطق الثلاث ← خريطة المعرفة ← الأمثلة الثلاثة (النموذج التوضيحي)
← قدرة التحليل ← رحلة الباحث ← الجمهور ← العربية أولًا ← الذكاء المسؤول ← خارطة الطريق
← نموذج الاستدامة ← المعجم ← الأسئلة الشائعة ← التواصل.

## الرسومات التفسيرية

- `FrameVisual.tsx` — سحابة معرفية واسعة يُنتقى منها عدد محدود من الركائز لتكوين الإطار البيني.
- `RegionsDiagram.tsx` — المناطق الثلاث مع شريط المحادثة الملازم.
- `MapLayersDiagram.tsx` — طبقات الخريطة الأربع ومسار معرفي واحد مضاء.

الركائز التسع عشرة **لا تُعرض كلها** في أي رسم؛ يُعرض عدد محدود منها كمثال مع الأرقام الإجمالية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## البناء والنشر

```bash
npm run build
npm start
```

### النشر على Vercel

1. ارفع المجلد إلى مستودع GitHub.
2. استورد المستودع في Vercel — الإعدادات الافتراضية لـ Next.js تكفي.
3. لا توجد متغيرات بيئة مطلوبة.
4. بعد حجز النطاق: حدّث `metadataBase` في `app/layout.tsx` والبريد في `content/site.ts`.

## الوصول والأداء

- `lang="ar"` و`dir="rtl"` على مستوى الجذر.
- دعم `prefers-reduced-motion` في كل الحركات.
- تنقل كامل بلوحة المفاتيح مع حالات تركيز ظاهرة.
- الرسومات SVG أصلية بلا مكتبات خارجية.
